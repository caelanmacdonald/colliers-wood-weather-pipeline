# Power BI Workspace

This folder documents the **Colliers Wood Weather Dashboard** presentation layer.

The working report remains in Power BI Desktop. Keep its reusable logic here so the dashboard can be understood and rebuilt without relying on memory.

## Contents

- `model.md` — tables, fields, relationships and page plan.
- `measures.dax` — version-controlled DAX definitions.
- `screenshots/` — dashboard evidence after each meaningful visual revision.

When a measure or model decision changes in Power BI, update the corresponding text file in the same work session.
